# 30-minute WEKA DSX Air demo

| Minutes | Activity |
|---|---|
| 0–5 | Eight-backend topology and clean starting state |
| 5–12 | Cluster creation and filesystem |
| 12–16 | Client mounts and shared file write/read |
| 16–21 | fio write/read verification |
| 21–26 | GUI health, drives, filesystem and clients |
| 26–30 | Clean checkpoint workflow and questions |

Start with a booted prepared lab and configured GUI service. Rehearse creation timing; keep a prepared healthy cluster as fallback. Use a short recording for full disk wipe, checkpoint creation and boot because duration varies. Pause recording during credential entry. Capture actual health and test outcomes rather than narrating expected success as completed evidence.
